# *Drift* — Exhibition & Critical Texts

Curatorial and critical material for the sound work *Drift* (2026). These texts
accompany the instrument itself (see the project root `README.md` for how it is
built and run).

| File | Use |
| --- | --- |

| [`STATEMENT.md`](STATEMENT.md) | First-person artist statement |

## The work in one breath

> *Drift* is an infinite, unrepeatable soundscape, synthesised live and never
> recorded, that you can influence but never command. Press **Cosmos** and it
> tunes itself to the real solar wind — measured a million miles from Earth —
> and lets the Sun choose the key.

*“You may nudge it. You will never hold it. That is the work.”*
